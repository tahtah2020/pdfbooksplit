How to find the PDF page where book page 1 appears

  1. Open the PDF and scroll past the cover, title page, copyright page and contents.
  2. Find the first page that carries the printed number 1 (or the first page of chapter 1).
  3. Look at the page counter in your PDF viewer, not the number printed on the page. That counter value is what you type in the first box.

When the offset is not constant

One offset works while the page numbering is continuous. Some books restart numbering in each part, add plates of photographs without page numbers, or use roman numerals for the front matter. In those cases use the offset of the section you are converting, and check the first and last page of each chapter in your viewer.

Questions

How do I convert a book page number to a PDF page number?

Add the offset. The offset is the PDF page that holds book page 1, minus 1. If book page 1 is on PDF page 14, the offset is 13, so book page 41 is PDF page 54.

Why does the PDF page number differ from the number printed on the page?

The PDF counts every page from the cover onward, including the title page, copyright page and contents. The printed number usually starts from the first page of the main text.

What if the front matter uses roman numerals?

The roman numerals are on pages before book page 1. They do not change the offset, which is measured from book page 1. To convert a roman-numbered page, count back from book page 1 in your viewer.

Does the calculator upload my PDF?

No. It only does arithmetic on the numbers you type, in your browser. There is no file and no upload.
